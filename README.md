# Nidhi & Jinay — Wedding Invitation Website

A lightweight, responsive wedding invitation website built with plain HTML, CSS, and JavaScript. No build tools, frameworks, or paid hosting required.

## Publish free with GitHub Pages

1. Sign in to GitHub and create a **new public repository**, for example `nidhi-jinay-wedding`.
2. Upload `index.html`, `style.css`, and `script.js` from this folder to the repository root. You can upload `README.md` too.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. Wait a minute or two. GitHub will show the published website URL, usually `https://YOUR-USERNAME.github.io/nidhi-jinay-wedding/`.
7. Open the URL on your phone and share it on WhatsApp along with the Canva invitation PDF/image.

## Notes

- All hosting is free through GitHub Pages.
- Google Fonts and Google Maps links need an internet connection.
- The site is static and does not collect visitor data or require a backend.
- Before sharing, check Gujarati wording and the event details against the original invitation. The English event labels are explanatory translations.
